# $Geospatial_Data_Acquisition$
Geospatial Data Acquisition workflow that includes reasoning on data modeling, source strategy, quality assessment, validation, assumptions made and tradeoffs.

### $Setup$

To create an enviroment which contains all relevant packages for this analyis to be run and reproduced...

**Using Conda**

create the environment by running this in the Mac OS Command line Interface AKA the Terminal. 

`conda env create -f environment.yml`

Activate it by running:

`conda activate geo-analysis-env`

to view notebooks and run code, I use the jupyter lab IDE - run the following in the Mac OS command line or Windows Git Bash:

`jupyter lab`
